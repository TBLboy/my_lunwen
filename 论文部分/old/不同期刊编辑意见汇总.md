# 不同期刊编辑意见汇总

## IEEE Transactions on Automation Science and Engineering（T-ASE）：创新性不足、方法必要性不够明确、实验过于理想化

编辑认为论文的创新程度较低，主要建立在已有的 DMD 和数据驱动 LQR
控制方法之上，没有充分体现所提出方法相较于现有技术的显著创新。同时，现有实验虽然能够验证方法有效，但实验条件过于理想化，没有设置足够具有挑战性的场景，因此无法充分体现该方法的必要性和优势。尤其是论文没有很好回答"为什么需要这一特定方法（why
we need this particular
approach）"这一核心问题。此外，编辑认为目前工作的整体贡献更偏向控制领域，与
T-ASE 的期刊定位匹配度有限，更接近控制领域会议论文。

## IEEE/ASME Transactions on Mechatronics（TMECH）：研究贡献偏控制领域，与机电一体化期刊定位不匹配

编辑委员会认为，该论文的潜在贡献主要集中在控制（controls），而不是机电一体化（mechatronics）。因此，论文与
TMECH
的期刊定位不够匹配。编辑建议将论文投稿至更加核心的控制工程期刊，例如
IEEE Transactions on Control Systems
Technology（TCST）。该期刊的意见主要集中在研究方向和期刊 scope
的匹配问题，并没有进一步指出具体的技术错误。

## IEEE Robotics and Automation Letters（RA-L）：技术深度和完整性不足，未达到期刊预筛选要求

论文经过 Associate Editor、Senior Editor 和 Editor-in-Chief
的预筛选，三者均认为目前稿件没有达到 RA-L 对论文技术实质（technical
substance）的最低要求，因此没有进入进一步外审。编辑意见主要集中在特征选择方法的理论依据、Koopman
模型的数据依赖性、与传统线性化方法相比的优势，以及实验验证强度等方面。

### RA-L：特征选择方法缺乏理论分析和高维系统验证

编辑质疑所提出方法进行特征选择时的效率。目前论文缺少相应的理论分析或验证，同时实验仅在
3-DOF
机器人系统上进行。因此，编辑提出当系统状态维数进一步增加时，该特征选择方法是否仍然有效，以及其计算效率和可扩展性是否能够得到保证。

### RA-L：Koopman 线性模型的数据依赖性和泛化能力不明确

论文通过 Koopman lifting
将非线性系统转换为升维空间中的线性系统，但编辑认为该线性模型对采集数据的依赖程度没有解释清楚。尤其需要回答该模型是否仅在建模数据附近的局部区域有效。如果控制任务或者参考轨迹明显偏离用于建立模型的数据分布，所提出方法是否仍然能够保持有效性和控制性能。此外，论文中
bounded disturbance assumption 的定义也需要进一步明确。

### RA-L：与传统动力学线性化方法相比的优势不明确

论文最终基于得到的线性系统设计 LQR
控制器，但编辑认为论文没有充分说明这种方法相比其他动力学线性化方法的优势。例如，对于非线性系统，本身可以通过
Jacobian 矩阵进行局部线性化，然后设计 LQR
控制器。因此，需要进一步证明采用 Feature Selection + Koopman Modeling +
LQR 的方案相比 Jacobian linearization + LQR
等传统方法究竟能够获得什么额外收益。

### RA-L：实验任务过于简单，缺少更复杂的真实机器人验证

目前实验主要是在 haptic device
条件下完成简单的参考轨迹跟踪。编辑认为这种实验不足以充分验证方法在复杂机器人控制任务中的有效性，建议增加真实机械臂上的更高级、更具有挑战性的控制任务，从而证明方法在复杂场景下的实际价值。
