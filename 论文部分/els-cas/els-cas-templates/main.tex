\begin{abstract}
Extended Dynamic Mode Decomposition (EDMD) provides a practical route to Koopman-based modeling by representing nonlinear robot dynamics as linear evolution in a lifted space. Its accuracy, however, depends strongly on the chosen dictionary: a small dictionary may miss important nonlinearities, while an overcomplete one can introduce redundancy, ill-conditioning, and unnecessary computation. We propose a feature-selection-based Koopman representation learning framework that retains the interpretability of a physics-informed candidate library while learning a compact set of linear feature combinations. The selection matrix is optimized jointly with the Koopman matrices, and the resulting problem is solved by block coordinate descent with stationary-point convergence guarantees under standard assumptions. The learned lifted model is then used in a feedforward-feedback linear quadratic regulator that treats finite-dimensional approximation errors and external uncertainties as bounded lumped disturbances. Lyapunov analysis shows that the closed-loop tracking error is ultimately uniformly bounded and relates the disturbance level to the steady-state error bound. The method is evaluated on a three-degree-of-freedom rigid robot arm and a cable-driven soft platform. The proposed feature-selection-based EDMD (FS-EDMD) model achieves lower multi-step prediction errors than EDMD and Extended Dynamic Mode Decomposition with Dictionary Learning (EDMDDL), and the resulting controller reduces tracking error relative to a PID baseline over multiple references. A disturbance-recovery test on the robotic arm further demonstrates bounded deviations and smooth recovery.
\end{abstract}
